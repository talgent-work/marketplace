# Opening a Cycle

A Cycle is the Project's next step toward its Vision. Read the direction first: the Vision, the Areas with their Capabilities, and the Cycles so far. Everything settled here goes into the hand-off (`talgent-runtime:handing-off`); the Project Work plans and opens the Cycle.

## Steps

Interview the Owner (`talgent-runtime:interviewing`) through each step, in order, since each builds on the one before:

1. **Goal.** Settle what this step accomplishes toward the Vision, and a window that starts after the previous Cycle ends. Check the window against the Cycles already planned.

   Done when the Owner accepted both.
2. **Expected Capabilities.** For each Area the Goal moves, settle the Capability it makes true by the Cycle's end. Each must be plainly true or false then.

   Done when each is accepted and names an existing Area, or one the hand-off defines.
3. **Intents.** Read the pool and, after a review, the Intents the Owner moved on. Propose those that deliver the Expected Capabilities, and settle the missing work as new Intents, each by its one-sentence title.

   Done when every Expected Capability has at least one Intent, or the Owner accepted it without one.
4. **Open.** Settle with the Owner that the Cycle opens once planned.

Done when the hand-off holds the whole Cycle: Goal, window, Expected Capabilities, its Intents, and whether it opens.

An Intent belongs to the Cycle and nothing more: none of its fields refers to the Cycle Goal or an Expected Capability.
