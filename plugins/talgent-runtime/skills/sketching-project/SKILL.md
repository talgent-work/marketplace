# Sketching a Project

Read the direction first. A Project that already has a Vision or Areas is refined, never started over. Everything settled here goes into the hand-off (`handing-off`); the Project Work makes it so.

## Map the ground

1. **Name what this Alignment settles**: the Topic, in the Owner's words.
2. **List the open questions across the whole sketch** before going deep on any: the Vision, the parts the undertaking splits into, each part's edges and what it can do today.
3. **Mark what is not yet clear enough to ask**, and keep it in the hand-off.

## Settle it

Interview the Owner (`interviewing`) one open question at a time, writing each settled part into the hand-off whole:

1. **Vision**: one sentence, the end state once the Project succeeds and for whom. An overview for newcomers is optional.
2. **Areas**: the parts the Vision splits into. Each carries one part of it, and together they cover it. Settle the list of names.
3. **Each Area**:
   - its positioning: which part of the Vision it carries;
   - its boundaries: what it will not do, binding every Intent in it;
   - its Capabilities: what holds today; an Area may start with none.

An Area records only what holds now. A target belongs to a Cycle.

Read the existing Intents and settle which Areas they serve. For an Area to remove, name the Intents in it.

Done when the Owner sees the sketch in the hand-off as settled.
