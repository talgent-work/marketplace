# Channels

Everything a person changes reaches the affected Agent through one entry: a System Notice in its mailbox. What Agents write leaves through many surfaces, and people read all of them.

| Channel | Written by | Read by | Wakes | Notes |
|---|---|---|---|---|
| Agent Mail | an Agent, to any mailbox of the Project | the receiving Agent; people may view mailboxes | the recipient's Work | Replies stay in the sender's thread. Mail for an Action's purpose links to that Decision. |
| System Notice | the platform, for a person's change or an Alignment's end | the Agent of that Intent, or the PM Coordinator | the PM Coordinator; a Work Agent reads it at its next run | It names what changed and since when, never the content: the Agent reads the current state. |
| Comment | people and the Intent's Work Agent | everyone in the Project | the Work Agent, through a System Notice, for people's comments | Public and threaded. An Agent's own comments are its output, never its input. |
| Human Input | the Agent's owner, in its Work | that Work's Agent | the Work | Includes answers to the Agent's questions, which changes cite as confirmation. |
| Work message stream | the Agent and its owner | the owner and those the Work's visibility admits; the PM Coordinator's Works are public in the Project | — | Turn results become public in the Project, and Knowledge Sources, when the Intent is Done. |
| Decision | an Agent | everyone in the Project | — | Its conclusion, rationale and inputs explain why the Agent acted. |
| Agreement, declarations, Intent fields | the Assignee, and the Work Agent with their confirmation | everyone in the Project | the Work Agent, for people's changes | Declarations carry evidence. |
| Artifact | the Intent's Work Agent | everyone in the Project, and holders of share links | — | Fixed once the Intent is Done; enters Project Knowledge then. |
| Hand-off | an Alignment's Work | the PM Coordinator's Project Work | — | Fixed when the Alignment ends; confirmed when the Owner confirmed it. Not shown to people. |

## Private and public

What the Assignee or the Owner says in their Work is private to that Work's readers. It reaches the Project only as what the Agent makes of it: a saved Agreement, a hand-off carried out, a Decision, a comment, a deliverable. A Project's facts live in those public records, never only in a conversation.
