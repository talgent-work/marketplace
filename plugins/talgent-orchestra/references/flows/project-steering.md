# How a Project is steered

## Alignments settle, the Project Work acts

The Owner and the PM Coordinator settle the direction in Alignments. An Alignment's Work changes nothing in the Project: everything settled in it goes into its hand-off. The Owner confirms the hand-off when the Alignment ends. The PM Coordinator's Project Work then reads it, makes the changes it lists, and tells the Intents they touch.

- **Beginning.** Either side begins an Alignment on one Topic. The PM Coordinator invites the Owner when something needs them: a Cycle Review, a step that runs into an Area's boundary, a change to the Vision, an Area or a Cycle, or a hand-off change the platform refused. The Owner may accept, decline or leave an invitation.
- **Ending.** The Agent asks the Owner to confirm the hand-off and ends the Alignment. An Alignment the Owner ends themselves leaves an unconfirmed hand-off, which informs the Project Work but authorizes no change to the direction.
- **After.** The end reaches the Project Work as a System Notice naming the Alignment.

## Sketching

A new Project's first Alignment usually sketches it: the Vision, and the Areas with their positioning, boundaries and current Capabilities. The hand-off lists them, and which existing Intents belong in which Area. A later Alignment may redraw the sketch.

## A Cycle

1. **Opening.** An Alignment settles the Cycle Goal, a window after the previous Cycle, the Expected Capabilities, each naming an Area, and the Intents the Cycle takes, from the pool or as new work. The Project Work plans and opens the Cycle and places its Intents.
2. **Running.** Work Agents realize the Cycle's Intents. In each Round the PM Coordinator looks for stalled work, dependencies unblocked or broken, Intents drifting from the Cycle Goal, and the window running out. It coordinates through Mail and the Intent structure.
3. **Review.** Once the window has passed, or every Intent of the Cycle that is not Cancelled is Done, the PM Coordinator invites the Owner to a Cycle Review. The Owner:
   - judges each Expected Capability;
   - has each Achieved one rewritten into its Area's Capabilities;
   - moves each unfinished Intent to the next Cycle or back to the pool.

   The same Alignment usually goes on to open the next Cycle. The Project Work carries out the review and the opening from one hand-off.

## Outside Alignments

The Owner may change the direction at any time. Each change reaches the PM Coordinator as a System Notice. Work Agents read the direction when their work depends on it.

## Closing

The Owner closes the Project once no Intent is In Progress or In Review and no unfinished Intent has an open Work. Closing is final; everything stays readable.
